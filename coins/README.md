# Coin logos

Generated — do not edit by hand. Run `npx tsx scripts/syncCoinIcons.mts` to refresh.

Source: [`cryptocurrency-icons`](https://github.com/spothq/cryptocurrency-icons),
released under **CC0-1.0** (public domain dedication). Only the assets Kraken
currently lists in EUR are copied here.

Coverage is partial by nature — the set predates most recent listings, so it
covers every one of the ten curated majors and most established assets, but
about a sixth of the full EUR universe. Everything else renders a generated
letter tile (see `src/ui/coinLogo.ts`); a missing file is a normal case, not an
error.
